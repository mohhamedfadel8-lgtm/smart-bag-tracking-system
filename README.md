# Smart Bag Tracking System

🎥 **[Watch the Demo Video on LinkedIn](https://www.linkedin.com/posts/mohamed-fadel-200741313_iot-smarttracking-iotapplications-activity-7371900464600186880-fSy_)**

An IoT and web-based system that brings together GPS tracking, sensor monitoring, and real-time alerts to provide security and convenience for tracking bags. Developed as an **ITI Graduation Project**.

---

## 📋 Overview

The Smart Bag Tracking System combines IoT hardware with a web application to give bag owners and customer service agents real-time visibility into a bag's location and status, with automatic alerts on suspicious activity.

---

## ✨ Features

- 👜 **Real-time tracking** of bags using GPS sensors
- 💡 **Status monitoring** with light sensors to detect if the bag has been opened
- 📍 **Interactive map display** showing the exact bag location with custom icons
- 🔐 **PIN-protected access** to securely store and access bag owner details
- 📧 **Instant email alerts** if the bag is opened, tampered with, or moved unexpectedly
- 🌍 **Geo-fencing** to notify users if the bag moves outside a predefined safe zone
- 🌐 **Web interface** for customer service agents to monitor and manage bags easily

---

## 🛠️ Tech Stack

- **JavaScript** — core application logic and web interface
- **IoT sensors** — GPS module and light sensor for real-time data
- **Interactive mapping** — live location display with custom markers
- **Email service integration** — instant alert notifications

---

## 🔄 How It Works

1. GPS and light sensors continuously monitor the bag's location and open/closed state.
2. Sensor data is sent in real time to the web application.
3. The bag's location is displayed on an interactive map with a custom icon.
4. If the bag is opened, tampered with, or moves outside its geo-fenced safe zone, an instant email alert is sent to the owner.
5. Customer service agents can monitor and manage all tracked bags through a dedicated web interface, with owner details protected behind PIN access.
